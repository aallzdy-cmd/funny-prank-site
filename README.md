# موقع المقلب المضحك 😂

موقع لمقلب مضحك يظهر رسالة اختراق وهمية ثم يتحول لرسالة حب وفرحة!

## ✨ المميزات
- تصميم واقعي لشاشة اختراق
- مؤثرات بصرية وحركية رائعة
- عد تنازلي مشوق
- مفاجئة جميلة في النهاية
- موسيقى احتفالية
- يدعم اللغة العربية والتصميم المتجاوب

## 🚀 كيفية الاستخدام
1. رفع الملفات على GitHub Pages
2. إرسال الرابط للضحية
3. الاستمتاع برد الفعل!

## 📁 ملفات المشروع
- `index.html` - الصفحة الرئيسية
- `style.css` - التنسيقات والمؤثرات البصرية
- `script.js` - المؤثرات التفاعلية
- `README.md` - ملف الشرح هذا

## ⚠️ ملاحظات
- الموقع آمن ولا يحوي أي برمجيات خبيثة
- صمم للمزاح والضحك فقط
- تأكد أن الضحية ستضحك معك في النهاية

## 🎨 تخصيص الموقع
يمكنك تعديل:
- النصوص
- الألوان
- توقيت العد التنازلي
- الرسائل

## 📝 الرخصة
مشروع مفتوح المصدر للاستخدام الشخصي المسلي فقط!
